Import products

Your 16 starter products live in the site's code, so they can't be edited here until you import them. The import tool copies them into this admin panel — after that you can edit, reorder or delete them like any other product. Products that are already imported are skipped, so it's safe to run again.

Orders

An order is saved here when a customer taps "Send order via WhatsApp" or "Order via Instagram DM" at checkout. Check your WhatsApp or Instagram to confirm they actually sent the message.

Promo codes

Customers type these at checkout (in the cart or on Buy Now). Changes reach the shop within a few seconds. Switch a code off to pause it without deleting it.

Move photos to Cloudinary

Uploads the 16 starter products' built-in photos to Cloudinary and gives you a lighter src/data/products.js to put on GitHub. This takes about 1.6 MB off your site, so it opens much faster.

Export Meta catalog

Downloads a CSV of all products for Facebook/Instagram: Commerce Manager → Catalog → Data sources → Upload. Re-download whenever you add products or change prices.
