Migrate Seed Photos

What this does

Your original 16 starter-catalog products still carry their photos as raw image data baked directly into the site's code, instead of using fast links the way every photo you've added since has. That makes your site's code noticeably heavier to load.

This one-time tool uploads those … photos to your Cloudinary account, then builds you a ready-to-use replacement for one file in your project — src/data/products.js — with fast links in place of the raw data. Nothing on your live site changes visually, and nothing in your admin database is touched — any of these 16 products you've already imported into the admin portal already use fast links and are unaffected either way.

Done — get your updated file

All photos uploaded successfully. Here's what to do next:

  1. Click "Download updated products.js" below.
  2. Open your project on GitHub and go to src/data/products.js.
  3. Click the pencil (Edit) icon.
  4. Select all the existing text (Ctrl/Cmd+A) and delete it.
  5. Open the file you just downloaded, copy everything in it, and paste it into GitHub.
  6. Commit the change — Vercel will redeploy automatically in a minute or two.
