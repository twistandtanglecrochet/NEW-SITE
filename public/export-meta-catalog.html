TTC Admin — Meta Catalog Export

Export your products for Meta

This reads every product currently on the shop — the ones you added in the admin portal plus any starter products — and builds a CSV file you can upload to your Meta catalog (Commerce Manager → Catalog → Data sources → Data feed → Upload once).
