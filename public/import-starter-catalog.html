What this does

Your 16 starter-catalog products currently live directly in the site's code, not in the same database the admin portal manages — so you can't edit or delete them from admin.html. This one-time tool copies each one into that database. Once a product is imported, it'll show up in the admin portal's "Current products" list, fully editable and deletable there, just like anything you add yourself.

Your live site won't change in any visible way — the products will look exactly the same to customers. This is safe to run more than once: anything already imported is automatically skipped, so you can't create duplicates by clicking twice.
